# 商品资料发布澄清（PUB-02）

用户反馈OpenPlay新介绍和视频未显示在浏览页。本轮普通公开浏览器分别核实中文/英文详情页均没有视频、仍为旧介绍；读取用户已有登录态脚本被安全检查拒绝，桌面原生观察因辅助权限不可用失败，因此尚不能确定生产草稿停在哪个阶段。不能把推测写成真实未点击发布或数据丢失。

修正已确认的UX问题：保存按钮名为“保存草稿”；独立“发布商品资料”准备按钮先保存当前输入，再显示确认，准备动作绝不发布。状态同时标明线上旧资料和本次待发布。确认显示具体字段、中文说明前后对照、视频计数和标题，中文变更/英文未改给出提示。视频空标题/空来源可直接定位；成功后有双语公开页链接。原纯预览不保存，软件独立发布不动商品，认证和存储未放宽。

不迁移、删改或公开用户生产数据；部署新界面不等于OpenPlay资料已发布。
