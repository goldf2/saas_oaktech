# 单一商品列表（DASH-02）

## 目标与设计

工作台将软件目录与商品管理合成一个商品列表，保留账号与支持。管理员在同一卡片编辑资料、管理版本并查看已发布详情/下载；普通用户使用同一路径和卡片结构，但数据仅投影已公开商品/发布记录，不含草稿名称、图片、软件文件和私有数量。

公开商品与已发布软件是独立状态。没有安装包的已上架商品继续可浏览，不出现虚假的下载按钮。商品尚未上架时不出现公开详情链接，已发布软件的既有下载路径不修改。

服务端基于getStoreAdmin确定模式，不接受查询参数或客户端canManage作为授权来源；旧/admin路径保留权限检查。view=library兼容转到view=products，保留q/state；普通用户的草稿筛选无效，不执行私有搜索。共同筛选只作用于该角色安全投影之后的数据。

复用现有商城数据和已发布版本筛选，草稿与公开快照分别取值；不引入第二份商品、不修改生产目录、订单或权限、不顺带实现多平台/GitHub或本地超管。

## 验证计划

纯函数验证名称、图片、统计、下载条件与查询参数；真实隔离Chrome检查管理员/普通用户/匿名访问、公开商品的私有修改、私有软件元数据、旧目录链接、空结果、390px移动布局、两种主题、变更角色后没有客户端缓存泄漏。继续跑原商品工作台和独立发布回归。

本轮基线remote main 4bc7e98（0.1.33），原主目录修改保留在原位置。验证、版本号、提交与生产观察逐项记录，不能预先标记已部署。
