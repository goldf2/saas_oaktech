# 应用商店式展示与平台预置多选（STORE-04）

## 依据与范围

用户要求参考Google软件商店、App Store，改善页面与元素结构，并把支持平台改为预置多选。基线为实际远端2a25a66 / 0.1.37。参考官方页面的信息层级，不复制商标、页面素材或评分数据：

- https://developer.apple.com/app-store/product-page/ ：图标、名称、简短副标题、截图/预览、介绍、版本信息分别组织。
- https://play.google.com/store/apps/details?id=notion.id ：实际读取桌面展示，首部身份/获取入口、截图横列、主体介绍与侧栏信息。
- https://apps.apple.com/us/app/notion-notes-tasks-ai/id1232780281 ：网页解析可读；本机浏览器访问跳转到中国区Today，另观察到精选卡片和目录层级。不可宣称本机看到原美区详情截图。

## 页面安排

首页采用简洁标题、真实商品的精选展示、搜索/类别/平台筛选及统一图标卡片。去掉巨幅口号、每个商品重复大封面、宽泛宣传模块。所有列表取公开数据；没有评分、购买量、下载量或定价来源，不创造这些字段。

详情页：图标＋名称＋副标题＋产品阶段，右侧获取入口；简短信息带；主体为截图横向画廊、视频、详细介绍、版本更新与下载，右侧放商品信息和支持入口。没有软件时明确暂无下载，介绍仍可先公开。截图支持横向滚动、放大、方向键和Esc。图标不再当成巨幅截图重复显示。

后台沿用商品资料／软件版本／预览发布。预览与正式详情使用同一渲染；手机预览使用容器尺寸，不能仅缩窄桌面页面。标题/封面可选的视频、自动加载且不自动播放、商品发布无额外勾选保持。

## 平台与类别

支持平台预置Windows、macOS、Linux、Android、iOS、浏览器插件、Web；更多环境提供Chrome、Edge、Firefox、Safari、TradingView。多选不等于安装包已可用；下载仍由已发布软件包决定。已保存的非标准平台保留可见、允许主动移除，不默默丢失。别名只用于显示/勾选匹配，未操作的已有原值不迁移。

商品类别提供AI工具、建模软件、实用工具、效率工具、开发工具、设计工具、交易研究工具。历史桌面应用/浏览器扩展类别保留编辑入口，不擅自替用户修改记录。导航中的浏览器插件转为平台筛选；新用途类别详情可正常浏览，并跟随当前语言。

## 验收与安全

在临时目录与回环服务运行测试，合成身份只用于本地。验证平台多选保存、历史值保留、草稿隔离、无软件发布介绍、图库键盘操作、真实搜索和过滤、中英文、浅/深色与320/390/768/1440宽度。复用既有发布、版本、上传、视频和语言回归，不把旧测试数量当作当前结果。

服务端鉴权、发布指纹、软件校验和分发链接不改；无生产商品、安装包或角色写入。记录本轮测试、提交、推送、CI、实际公网部署分别是否完成。第三方视频响应在默认隔离测试中替代，不声称其真实播放通过。

## NAV-01：主导航层级

顶部与手机公共主菜单只放产品、支持；浏览器扩展属于产品目录的平台筛选，不再设为一级入口。页脚及原筛选地址仍兼容。本调整不改变商品分类或发布逻辑。
