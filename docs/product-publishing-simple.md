# 简化商品发布与视频播放（PUB-02，0.1.37）

## 当前约定

商品资料与软件版本仍各自发布；商品介绍可以早于任何安装包公开。商品资料发布检查页不再要求额外勾选“我确认”：管理员明确点击“发布商品资料”就是发布意图。只打开预览、切换页签、保存草稿均不发布。软件安装包的独立选择、校验及确认维持原样。

视频的显示标题和封面均为可选。空标题、只有空白字符、旧客户端省略标题均归一为空字符串；展示时使用“视频介绍”或“Video introduction”。这个默认名称不是从视频平台抓取的元数据。无有效来源、非法或重复链接仍会提示处理；不会隐藏丢弃不完整视频来冒充发布成功。

YouTube、B站使用已适配且固定来源的播放器，直接渲染iframe，不再显示“加载播放器”按钮。浏览器可对远离视口的播放器延迟联网，进入视频区域会自动加载，无需额外点击。autoplay=0，不授予自动播放权限。换源替换旧iframe，关闭预览/切出预览页会销毁播放器。未适配来源依旧是安全外链，不接受任意iframe代码。

## 操作

商品资料 → 添加视频 → 粘贴完整链接 → 标题和封面可留空 → 发布商品资料 → 检查更新范围 → 点击发布商品资料。最后一步不再额外勾选复选框。保存草稿或纯预览不会更新线上。

## 不变的服务端边界

原发布动作只在最终按钮点击时发送明确的confirm字段，并继续验证管理员身份、已保存草稿指纹、图片归属与存在性、链接及长度/数量。不移除服务端校验，不自动选择/发布软件，也不执行已有生产草稿。

本轮同时保留0.1.36双栏排版、页签滚动定位、未保存输入保护；保存成功立即显示“待发布”，不再等待路由刷新才显示。之后再次编辑/上传会清除上一次发布回执，避免把新草稿误标为已发布。

## 验收

单元、动作、类型、构建和隔离Chrome分别运行；原生签名验证与真实平台播放未因iframe请求成功而被宣称通过。专用浏览器用临时目录和回环服务器，外部视频响应以标明的测试内容替代；验证自动请求、autoplay参数、切源卸载、公开与草稿隔离，而不是声称第三方服务在所有网络均可播放。
