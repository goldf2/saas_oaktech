## 如何操作

进入商品的“软件版本”：填写资料，点击“保存版本并继续上传”；在解锁的区域选择或拖入文件，核对自动建议，点击开始上传。确认下方服务器文件记录齐备，再点击“继续：校验预览”。预览会提示商品资料和版本文件缺项；补齐/保存后勾选待发布版本和最后确认，执行“校验并发布”。已发布版本显示实际下载入口，未选草稿不会公开。

网页上的文件齐备判断只是前置提示，不代替服务器的签名校验；本轮实际测试曾篡改临时文件确认发布被拒，恢复正确文件后再明确确认，最终匿名GET内容一致。
