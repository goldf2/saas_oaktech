# 商品与软件独立发布（PUB-01）

目标：版本仍归属商品，不恢复全局平级软件表单；资料发布与软件发布拥有独立的提交、校验、确认及指纹。

商品资料：可无安装包先上架；只提升已保存的名称、图文、视频和展示状态，不读取或切换版本。
软件版本：只要求归属商品记录已创建；只校验并提升选中的版本与制品，不要求封面/介绍齐全，不消费已保存商品草稿，也不保存未保存的文案。发布是显式公开下载的操作，即使商品介绍页尚未上架，也不得把它称为仍私有。

预览发布保留两个明确模式“商品资料发布”“软件版本发布”，分别确认。软件预览使用已公开商品资料加所选版本，不能把正在修改的介绍显示为本次即将公开。未上架商品显示明确提示，不伪装成已公开页面。

原有JSON单写入模式、签名校验、平台/渠道模型保持；本任务不声称完成多平台版本线、GitHub同步或本地超级管理员。主目录未提交内容保留；所有验证使用临时数据，生产不发布样例。

用户进一步确认的主流程：先发布商品介绍，再发布软件。无任何版本时也能上架商品，不创建虚拟版本或下载；后来新增/发布软件时不重复发布商品介绍。此场景列入服务测试和真实浏览器验收。

进行中：拆分服务、动作、独立确认界面和预览。原复现测试证实旧逻辑会因版本变更使商品确认失效，也会在资料发布时隐式发布软件。最终验证结果另记，不能使用历史测试数量代替本轮验收。
