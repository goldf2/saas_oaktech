# 软件版本导入

IMPORT-01，商城 0.1.43。

软件版本页面默认从 GitHub Release 导入：输入公开仓库 `owner/repo` 或具体 Release 链接，读取最近 30 个公开版本，选择后自动填入版本号、渠道、标题和更新说明。没有更新说明时由管理员补齐。保存草稿后自动读取该 Release 的附件，核对平台、架构、包类型并确认导入。源码归档不作为安装包自动添加。

同一草稿可通过 HTTPS 文件直链或本地上传补齐文件。切换来源保留本地队列；远程导入成功后自动刷新版本文件。已保存版本资料折叠展示，缺失文件明确标为缺少及预期文件名。界面支持中英文与移动端。

远程来源目前支持公开 GitHub 仓库；没有新增私人 GitHub 授权或自动定时同步。直链支持带查询参数的下载地址，必须在有效期内完成下载。URL 不记入审计日志；不向远程站点转发管理员身份或凭据。

新接口均要求现有商城管理员会话及自定义请求头。服务器仅连接公开 IPv4 HTTPS 地址，每次重定向重新校验并固定解析地址；内网、环回及非 HTTPS 地址拒绝。单文件上限沿用 4 GiB，下载最长 15 分钟、无数据等待最长 30 秒；失败可重新导入。文件保存在原持久存储，沿用 SHA-512、不可覆盖及目录变更检查。

导入不是正式发布，仍经过原确认发布和签名校验；签名清单不改写。没有自动公开既有草稿，也没有替用户发布软件版本。

验证：`npm test`、`npm run typecheck`、`npm run build`、`npm run test:release-import`、`npm run test:release-ui`。导入浏览器验证使用临时目录与合成测试身份，读取公开 cli/cli 的真实 Release 附件，验证落盘字节、混合来源、重复拒绝、内网地址拒绝、匿名拒绝及手机双语界面；不写生产数据。
