# 缠序 / Auth 商品混用与后台入口修复

时间：2026-09-16T13:12:53+08:00；源码版本：0.1.23。

## 用户实际页面与根因

用户截图对应 `/dashboard` 的「Available to try」区域，并非发布管理页。检查确认：

- `public/chanxu-tradingview/icon.png`、`public/open-play/icon.png` 与 auth 项目的 `assets/icon-prepared.png` 原始 SHA-256 相同：`44fb0db5321d75edeb70f279b6717aa9223cfb95d87b6f9f2382d2cf77ce8ca9`。缠序错误使用了认证工具素材，并非仅名称相近。
- Dashboard 直接从 `config/products.ts` 读取静态 PRODUCTS，且只显示 beta：未录入生产持久目录的缠序仍显示，released 状态的 open play 却被排除。
- 桌面顶部按钮只有被识别为管理员时显示，手机菜单没有管理链接，个人中心无明确入口；未登录和非管理员访问旧后台都会获得404，用户无法判断是页面不存在还是缺权限。
- 本轮开始时公网 health 已为0.1.22，不能沿用上轮回复时的0.1.21状态；当时 `/admin`、`/admin/products/new`、两个商品的中文公开页仍为404。

## 实施内容

1. 图标：从缠序原有品牌图 `chanxu-social-card.png` / 商城 `overview.png`（两者SHA-256一致）提取「缠序」字标，保存为 `/chanxu-tradingview/icon-chanxu-v2.png`。替换旧兼容路径，并仅对已知旧图标路径作读取时映射；不覆盖管理员自定义图片，不修改auth项目。
2. 展示：Dashboard 改用 `listPublicProducts`，公开的正式版与测试版均可见；不再从静态种子虚构生产商品。商品slug、分类、平台和详情链接各自独立。
3. 后台入口：新增 `/admin` 总览与 `/admin/products/new` 独立新增页。桌面导航、手机菜单、个人中心、页脚均可找到管理入口；手机点击后关闭菜单，露出目标页面。
4. 权限说明：未登录显示登录提示，已登录但无管理员权限显示明确说明，不渲染商品字段、编辑表单或生产目录；所有写操作仍由原 `requireStoreAdmin` 校验。没有放宽白名单或自动提权。
5. 新增页：复用现有服务器校验和同一商品表单；提供空白、open play/Auth、缠序三种资料起点。两套商品模板各自对应分类与素材，默认draft，打开页面不保存、不公开、不发布软件包；已有商品引导编辑而非重复新建。

- `/admin/products`：管理已有商品。
- `/admin/releases`：管理软件版本与安装包。
